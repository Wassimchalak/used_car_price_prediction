This project analyzes and predicts used-car prices using a dataset of approximately 5,000 vehicles in R, with Price as the quantitative response variable and Brand, Model, Year, Odometer, Transmission, and Car Type as predictors. The workflow includes data cleaning, preprocessing, exploratory data analysis, outlier detection, and visualization using tools such as tidyverse, dplyr, and ggplot2. Simple and multiple linear regression models are used both for prediction and statistical inference, allowing the project to estimate the price of unseen vehicles while also examining how individual car characteristics are associated with price after controlling for the remaining predictors. Model quality is evaluated using measures such as R², RSE, MAE, RMSE, and residual behavior, while regression diagnostics are used to investigate nonlinearity, heteroscedasticity, outliers, high-leverage and influential observations, and multicollinearity using VIF. The project also applies train/test splitting to assess predictive performance on unseen data, combining statistical modeling, interpretation, diagnostics, and practical data analysis in a complete end-to-end regression workflow.
